Good to know

Requests are paced (the public site rate-limits), so a full cycle takes about 45 minutes. You can close this tab: the job keeps running and the page catches up when you return.

FAIL means failures were found. Today the known defects make the API tests, coded tests and defect reproduction fail by design; the report says whether anything new appeared.

With test steps in the same job, the report uses only that job's runs (a layer that failed shows as not run). "Report only" uses the latest complete run of each type, listed under the links.
