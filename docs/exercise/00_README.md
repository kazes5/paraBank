# QA Home Exercise: Package contents

| File | Purpose |
|---|---|
| `01_Exercise_Instructions.md` | The exercise: scenario, tasks, ground rules, deliverables. **Start here.** |
| `02_parabank_openapi.json` | Copy of the ParaBank OpenAPI spec (the live one is linked in the instructions). You can import it into Postman or Swagger Editor. |
| `03_Postman_Environment_Template.json` | Optional Postman environment with the base URL and empty variables to fill in. |
| `04_STD_Template.md` | Optional template for the Test Design Document. |
| `05_Bug_Report_Template.md` | Optional template for bug reports and spec questions. |
| `06_STR_Template.md` | Optional template for the Test Summary Report. |

The templates are optional. Use your own format if you prefer, as long as the same information is covered.
